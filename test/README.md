# Test data

Synthetic test data for ShoggoTEh. All files are generated by
`make_test_data.py` using `random.seed(42)` for full reproducibility.

## Contents

| File | Description |
|---|---|
| `genomes/test_species.fa` | 3 chromosomes (Chr1: 40 kb, Chr2: 25 kb, Chr3: 15 kb) |
| `repeats/test_species.bed` | Synthetic repeat intervals (LTR, DNA, LINE, SINE, Unknown) |
| `gff3/test_species.gff3` | 10 single-exon gene models |
| `species.tsv` | Single-row species table with absolute paths |

## Regenerating

```bash
python3 test/make_test_data.py
```

## Quick test — prepare_dataset.py only

`prepare_dataset.py` is the only step that can be tested without the
Hyena-DNA model weights. With the synthetic data (~75 kb genome, 5 kb
windows) it runs in under 30 seconds on a laptop.

```bash
conda activate shoggoTEh

python3 scripts/prepare_dataset.py \
    --species_tsv test/species.tsv \
    --outdir test/chunks/ \
    --chunk_size 5000 \
    --overlap 0.5 \
    --threads 1
```

Expected output: `test/chunks/test_species.parquet` with ~15–25 labeled
windows; `test/chunks/logs/Run_prepare_dataset.log`; `test/chunks/run_summary.json`.

Expected label distribution (approximate — window counts vary with overlap):

| Label | Typical count |
|---|---|
| `LTR` | 3–6 |
| `DNA` | 2–4 |
| `LINE` | 1–3 |
| `SINE` | 1–2 |
| `Unknown_repeat` | 1–3 |
| `Genic` | 2–4 |
| `Intergenic` | 3–7 |

## Why only Step 1 is testable without GPU

Steps 2–5 require the Hyena-DNA model weights (~1.5 GB download from
HuggingFace) and benefit significantly from a GPU. They are not
included in the quick test to keep the test zero-dependency.

To test the full pipeline end-to-end, download the model and run:

```bash
python3 scripts/generate_embeddings.py \
    --chunks_dir test/chunks/ \
    --outdir test/embeddings/

python3 scripts/train_classifier.py \
    --embeddings_dir test/embeddings/ \
    --outdir test/model/ \
    --epochs 5 --patience 3

python3 scripts/predict.py \
    --fasta test/genomes/test_species.fa \
    --model_dir test/model/ \
    --outdir test/predictions/
```
