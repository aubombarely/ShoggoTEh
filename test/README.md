# Test data

Synthetic test data for ShoggoTEh. All files are generated by
`make_test_data.py` using `random.seed(42)` for full reproducibility.

## Contents

| File | Description |
|---|---|
| `genomes/test_species.fa` | 3 chromosomes (Chr1: 40 kb, Chr2: 25 kb, Chr3: 15 kb) |
| `repeats/test_species.bed` | Synthetic repeat intervals (LTR, DNA, LINE, SINE, Unknown) |
| `gff3/test_species.gff3` | 10 single-exon gene models |
| `species.tsv` | Single-row species table with absolute paths |

## Regenerating

```bash
python3 test/make_test_data.py
```

## Quick test — prepare_dataset only

`ShoggoTEh.py prepare_dataset` is the only subcommand that can be tested
without the Hyena-DNA model weights (it still requires a system `bedtools`
binary, via `pybedtools`). With the synthetic data (~80 kb genome, 5 kb
windows, 50bp bins) it runs in under 30 seconds on a laptop.

```bash
conda activate shoggoTEh

python3 scripts/ShoggoTEh.py prepare_dataset \
    --species_tsv test/species.tsv \
    --outdir test/chunks/ \
    --chunk_size 5000 \
    --bin_size 50 \
    --overlap 0.5
```

Expected output: `test/chunks/test_species.parquet` with ~30 chunks, each
carrying a `bin_labels` array of 100 per-bin labels (`chunk_size / bin_size`);
`test/chunks/logs/Run_ShoggoTEh_prepare_dataset.log`;
`test/chunks/run_summary.json`.

Expected **bin-level** label distribution (approximate — bin counts vary
with overlap; each chunk contributes 100 bins):

| Label | Typical share of bins |
|---|---|
| `LTR` | moderate |
| `DNA` | moderate |
| `LINE` | low |
| `SINE` | low |
| `Unknown_repeat` | low |
| `Genic` | moderate |
| `Intergenic` | largest single share |

Unlike the old window-level pipeline (which discarded "mixed" windows and
could produce zero labeled windows for short, dispersed classes), every bin
is labeled — there is no discard step at this stage.

## Why only prepare_dataset is testable without GPU

`generate_embeddings`, `train_classifier`, and `predict` require the
Hyena-DNA model weights (~1.5 GB download from HuggingFace) and benefit
significantly from a GPU. They are not included in the quick test to keep
the test zero-dependency.

To test the full pipeline end-to-end, download the model and run:

```bash
python3 scripts/ShoggoTEh.py generate_embeddings \
    --chunks_dir test/chunks/ \
    --outdir test/embeddings/

python3 scripts/ShoggoTEh.py train_classifier \
    --embeddings_dir test/embeddings/ \
    --outdir test/model/ \
    --epochs 5 --patience 3

python3 scripts/ShoggoTEh.py predict \
    --fasta test/genomes/test_species.fa \
    --model_dir test/model/ \
    --outdir test/predictions/
```
